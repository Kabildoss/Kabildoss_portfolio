1. Create a PUBLIC GitHub repository named kabil-portfolio.
2. Upload index.html to the repository root and commit.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Once deployed, your URL should be https://Kabildoss.github.io/kabil-portfolio/

Add that URL to your resume only after confirming it opens publicly.
